ECOS DE SAL — paquete web limpio
=================================

Este paquete está preparado para subirlo manualmente desde cero.

ESTRUCTURA
----------
index.html
styles.css
script.js
config.js
assets/

IMPORTANTE
----------
- Las imágenes se cargan como archivos normales desde assets/.
- No se usa Base64.
- No incluye ningún archivo .b64.
- No cambies los nombres de los archivos de assets.
- Sube la carpeta assets completa junto a index.html.

PARA CLOUDFLARE PAGES
---------------------
Sube el contenido de esta carpeta como sitio estático.
No hace falta build command.
Directorio de salida: la propia raíz del proyecto.

NOTA SOBRE I WAS PAINTED SHUT
-----------------------------
La sección está preparada para usar:
assets/i-was-painted-shut-web.jpg

Si ese archivo está presente en assets, puede sustituirse directamente en index.html
en el bloque de la sección "I Was Painted Shut". El resto del sitio no depende de Base64.
